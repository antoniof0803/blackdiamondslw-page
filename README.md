# Black Diamond Barbershop

Landing estática tipo Beacons para Black Diamond Barbershop (Saltillo).

## Desarrollo

```bash
npm install
npm run dev
```

## Contenido editable

Edita links, textos e imágenes en:

`src/data/site.json`

Assets en `public/assets/`.

## Deploy (Vercel)

1. Importa este repo en Vercel.
2. Framework preset: Astro (build `npm run build`, output `dist`).
3. Conecta tu dominio en Project → Settings → Domains.
